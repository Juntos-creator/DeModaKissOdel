# De Moda KissOdel — High Fashion Portfolio for SHEIN X

Portafolio de lujo minimalista, 100% responsive, listo para postular a SHEIN X.

## Estructura de carpetas (para VS Code)

DeModaKissOdel-Portfolio/
├── index.html          → Tu página principal (no toques si solo agregas diseños)
├── css/
│   └── style.css       → Paleta, tipografía, layout boutique
├── js/
│   ├── data.js         → ⭐ EDITA SOLO ESTE ARCHIVO PARA AGREGAR DISEÑOS
│   └── main.js         → Lógica que genera todo automáticamente
├── images/             → Pon aquí tus fotos
│   ├── look1-organza-blouse.webp
│   ├── look2-plaid-cascade.webp
│   ├── look3-chocolate-corset.webp
│   └── embroidery-gold-macro.webp
└── README.md

## Cómo agregar más diseños (30 segundos)

1. Pon tu foto en /images/ (ej: look4-evening-gown.jpg)
2. Abre js/data.js
3. Copia un objeto completo { id: 1, ... } y pégalo al final
4. Cambia:
   - id: 4 (siguiente número)
   - number: "04"
   - title: "Nombre en inglés"
   - image: "./images/look4-evening-gown.jpg"
   - description y spec

¡Listo! No toques index.html ni CSS.

## Cómo usar en VS Code

1. Descarga el ZIP y descomprime
2. Abre la carpeta en VS Code
3. Instala extensión "Live Server"
4. Click derecho en index.html > Open with Live Server
5. Reemplaza las 4 imágenes de muestra con tus fotos reales

## Para SHEIN X

- Texto en inglés listo
- Tech packs con FABRIC, LINING, TRIMS, STITCH, FINISHING, MEASUREMENTS
- Botón Download PDF → conecta a tu archivo /portfolio.pdf
- Formulario → conecta a Formspree (https://formspree.io/) para recibir emails
